<h2>🗂️ Conteúdo dos Módulos</h2>
<ul>
    <li><b>Fundamentos da Plataforma Java:</b> Sintaxe básica, ambiente de desenvolvimento, primeiros desafios e projetos.</li>
    <li><b>Escopo e Estruturas de Controle:</b> Condicionais, loops, tratamento básico de exceções.</li>
    <li><b>POO:</b> Introdução a objetos, UML, construção de sistemas orientados a objetos.</li>
    <li><b>Estruturas de Dados:</b> Listas, filas, pilhas, árvores, collections, APIs de Streams.</li>
    <li><b>Gerenciamento de Dependências/Build:</b> Maven, Gradle, configuração de projetos, materiais complementares.</li>
    <li><b>Qualidade e Boas Práticas:</b> SOLID, debugging, testes unitários (JUnit, Mockito).</li>
    <li><b>Spring Framework:</b> APIs REST, segurança, JPA, padrões de projeto (em desenvolvimento).</li>
</ul>
